Portfolio Demo

Сайт-портфолио с админ-панелью

Демо-портфолио креативных работ: каталог по разделам, корзина, заказы, регистрация клиентов, профиль пользователя и полноэкранная панель администратора.

Разделы сайта
  • Фитнес-индустрия — каталог и карточки товаров
  • Мои баннеры — галерея, лайки и комментарии
  • Одежда — lookbook и fashion-каталог
  • Demo-режим — общая корзина и заказы для демонстрации
Стек
  • Frontend: HTML, CSS, JavaScript
  • Backend: Node.js, Express
  • База данных: MySQL
  • Развёртывание: Docker Compose
  • Почта: Brevo / Google Apps Script / SMTP
Запуск локально
  • git clone → cp .env.example .env → docker compose up -d
  • Сайт: http://localhost:3000
  • Подробности — в README репозитория
