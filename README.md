# Портфолио — демо-сайт с каталогом и админ-панелью

Публичный демо-проект: портфолио креативных работ с разделами **Фитнес-индустрия**, **Мои баннеры**, **Одежда** и **О сайте**. На сайте реализованы каталог, корзина, заказы, отзывы, регистрация клиентов и полноэкранная **панель администратора**.

Репозиторий: [github.com/YuliyaBagrova/portfolio-site](https://github.com/YuliyaBagrova/portfolio-site)

Лендинг репозитория (GitHub Pages): [yuliyabagrova.github.io/portfolio-site](https://yuliyabagrova.github.io/portfolio-site/)

## Возможности

### Публичный сайт
- Главная с hero-баннерами, статистикой и последними работами
- Каталоги по разделам с фильтрами, карточками товаров и страницами товара
- Поиск по работам с выпадающими подсказками
- Раздел «Мои баннеры» с просмотром, лайками и комментариями
- Корзина и страница заказов для клиентов
- **Demo-режим** — общая корзина и общие demo-заказы для демонстрации сценария покупки
- **Регистрация клиентов** — email, подтверждение кодом, профиль «О пользователе»
- Меню пользователя в шапке: профиль, корзина, заказы, вход/регистрация

### Панель администратора
- Управление работами, баннерами, каталогами и контентом разделов
- Заказы с сайта (включая пометку Demo)
- Настройка внешнего вида разделов и hero-баннеров
- Регистрация администратора с подтверждением email (Brevo / Google Apps Script / SMTP)

## Быстрый старт

### Требования
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (или Docker + Compose)

### Запуск

```bash
git clone https://github.com/YuliyaBagrova/portfolio-site.git
cd portfolio-site
cp .env.example .env
docker compose up -d
```

Сайт: **http://localhost:3000**

MySQL с хоста (DBeaver и т.п.):
- хост: `127.0.0.1`, порт: `3011`
- база: `portfolio`
- пользователь: `root` / `rootpassword`

Статические файлы (`*.html`, `*.css`, `*.js`) монтируются в контейнер — после правок достаточно обновить страницу (**Ctrl+F5**). Пересборка нужна только при изменении `package.json` или `Dockerfile`:

```bash
docker compose up -d --build
docker restart portfolio-app
```

### Локальный запуск без Docker

```bash
npm install
# MySQL должен быть доступен; параметры — в .env
npm start
```

## Клиентские сценарии

| Режим | Корзина | Заказы |
|-------|---------|--------|
| **Demo** | Общая (`demo:shared`) для всех demo-пользователей в браузере | Все demo-заявки |
| **Зарегистрированный клиент** | Личная, по `user:id` | Только свои, без demo |
